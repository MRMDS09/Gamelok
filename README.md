# لعبة النقاط والمربعات - Dots and Boxes Game

لعبة تفاعلية باللغة العربية مع مميزات متقدمة للهواتف الذكية.

## 🎮 المميزات

### الصفحات الرئيسية
- **صفحة البداية**: واجهة جميلة مع خيارات بدء اللعبة والإعدادات
- **صفحة اختيار الألوان**: اختيار ألوان مخصصة للاعبين من 12 لون مختلف
- **صفحة الإعدادات**: تحكم كامل في الصوت والموسيقى

### الأصوات والموسيقى
- **موسيقى خلفية**: قابلة للتحكم في التشغيل/الإيقاف ومستوى الصوت
- **أصوات النقر**: أصوات عند رسم الخطوط مع تحكم في مستوى الصوت
- **التأثيرات الصوتية**: أصوات إضافية للعبة
- **الاهتزاز**: تفعيل/إيقاف الاهتزاز عند النقر

### واجهة المستخدم
- **تصميم عربي**: واجهة باللغة العربية مع دعم كامل للنص العربي
- **ألوان مخصصة**: اختيار ألوان فريدة لكل لاعب
- **تنقل سهل**: نظام تنقل بديهي بين الصفحات
- **تصميم متجاوب**: يتكيف مع أحجام الشاشات المختلفة

## 🚀 كيفية التشغيل

1. تأكد من تثبيت React Native وبيئة التطوير
2. قم بتثبيت المكتبات المطلوبة:
   ```bash
   npm install react-native-svg
   ```
3. شغل التطبيق:
   ```bash
   npx react-native run-android
   # أو
   npx react-native run-ios
   ```

## 📱 الصفحات

### الصفحة الرئيسية
- زر بدء اللعبة
- زر اختيار الألوان
- زر الإعدادات

### صفحة اختيار الألوان
- معاينة مباشرة للألوان المختارة
- 12 لون مختلف للاختيار من بينها
- منع اختيار نفس اللون للاعبين
- حفظ الألوان المختارة

### صفحة الإعدادات
- **الموسيقى الخلفية**: تشغيل/إيقاف + تحكم في مستوى الصوت
- **أصوات النقر**: تشغيل/إيقاف + تحكم في مستوى الصوت
- **التأثيرات الصوتية**: تشغيل/إيقاف الأصوات الإضافية
- **الاهتزاز**: تفعيل/إيقاف الاهتزاز
- **إعادة تعيين**: إعادة الإعدادات للقيم الافتراضية

### صفحة اللعبة
- لوحة لعب تفاعلية 6x6
- عرض معلومات اللاعبين مع الألوان المخصصة
- أصوات النقر عند رسم الخطوط
- زر العودة للصفحة الرئيسية
- زر إعادة تعيين اللعبة

## 🎨 الألوان المتاحة

- أحمر، أزرق، أخضر، برتقالي
- بنفسجي، وردي، تركوازي، ذهبي
- رمادي، بني، أخضر فاتح، أزرق فاتح

## 🔧 التقنيات المستخدمة

- **React Native**: إطار العمل الأساسي
- **TypeScript**: للكتابة الآمنة
- **React Native SVG**: لرسم لوحة اللعب
- **Context API**: لإدارة حالة الصوت والإعدادات
- **Hooks**: لإدارة حالة المكونات

## 📝 ملاحظات التطوير

- تم تصميم نظام الصوت ليكون قابل للتوسع
- يمكن إضافة مكتبات صوتية حقيقية مثل `react-native-sound`
- يمكن إضافة المزيد من الألوان أو التأثيرات
- النظام يدعم إضافة لاعبين إضافيين بسهولة
