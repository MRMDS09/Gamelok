# لعبة النقاط والمربعات - Dots and Boxes Game

لعبة تفاعلية باللغة العربية مع مميزات متقدمة للهواتف الذكية.

## 🎮 المميزات

### الصفحات الرئيسية
- **صفحة البداية**: واجهة جميلة مع خيارات بدء اللعبة والإعدادات
- **اختيار اللوحة والخصم**: تحديد شكل اللوحة واللعب المحلي أو ضد الهاتف
- **صفحة اختيار الشخصيات**: سيكوك وبوحجرة، بشخصية مختلفة لكل لاعب
- **صفحة الإعدادات**: تحكم كامل في الصوت والموسيقى

### الأصوات والموسيقى
- **موسيقى خلفية**: قابلة للتحكم في التشغيل/الإيقاف ومستوى الصوت
- **أصوات النقر**: أصوات عند رسم الخطوط مع تحكم في مستوى الصوت
- **التأثيرات الصوتية**: أصوات إضافية للعبة
- **الاهتزاز**: تفعيل/إيقاف الاهتزاز عند النقر

### واجهة المستخدم
- **تصميم عربي**: واجهة باللغة العربية مع دعم كامل للنص العربي
- **ألوان الشخصيات**: لون ثابت لكل شخصية يظهر على لوحة المباراة
- **تنقل سهل**: نظام تنقل بديهي بين الصفحات
- **تصميم متجاوب**: يتكيف مع أحجام الشاشات المختلفة

## 🚀 كيفية التشغيل

1. تأكد من تثبيت Node.js وتطبيق Expo Go
2. قم بتثبيت المكتبات المطلوبة:
   ```bash
   npm.cmd install
   ```
3. شغل التطبيق:
   ```bash
   npx.cmd expo start
   ```

## 📱 الصفحات

### الصفحة الرئيسية
- زر بدء اللعبة
- زر الإعدادات

### مسار بداية المباراة واختيار الشخصيات
- الرئيسية ← اختيار اللوحة والخصم ← اختيار الشخصيات ← المباراة
- الضغط على بطاقة يخصصها للاعب 1، والشخصية الأخرى تتخصص تلقائياً للاعب 2 أو الهاتف
- عند أول تشغيل: سيكوك للاعب 1 وبوحجرة للخصم
- يُحفظ الاختيار فور تغييره، ويظل محفوظاً عند الرجوع وبين مرات تشغيل التطبيق

### صفحة الإعدادات
- **الموسيقى الخلفية**: تشغيل/إيقاف + تحكم في مستوى الصوت
- **أصوات النقر**: تشغيل/إيقاف + تحكم في مستوى الصوت
- **التأثيرات الصوتية**: تشغيل/إيقاف الأصوات الإضافية
- **الاهتزاز**: تفعيل/إيقاف الاهتزاز
- **إعادة تعيين**: إعادة الإعدادات للقيم الافتراضية

### صفحة اللعبة
- لوحة لعب تفاعلية 6x6
- بطاقات بوجوه الشخصيات الشفافة وأسمائها، مع فصل دور اللاعب أو الهاتف عن اسم الشخصية وإظهار النقاط
- الدور الحالي ظاهر بإطار بلون الشخصية ونص واضح، مع بطاقة جانبية مدمجة للشاشات الأفقية الصغيرة
- أصوات النقر عند رسم الخطوط
- زر العودة للصفحة الرئيسية
- تأكيد المغادرة عند وجود تقدم في مباراة جارية، مع إيقاف حركة الكمبيوتر مؤقتاً حتى متابعة اللعب أو تأكيد الخروج. يشمل زر الرجوع في Android.
- زر إعادة تعيين اللعبة

## 🎨 الشخصيات

- سيكوك: `sikouk`، اللون `#0F766E`، البطاقة `caracter/hero1.png` والوجه `caracter/hero1_face.png`.
- بوحجرة: `bouhajra`، اللون `#7C3AED`، البطاقة `caracter/hero2.png` والوجه `caracter/hero2_face.png`.
- التعريف المركزي للاسم واللون وصورتي البطاقة والوجه في `components/Characters.ts`؛ الصور الأصلية محلية ولا تتغير.
- المباراة تحمل معرّف شخصية كل لاعب إلى النتيجة مع نقاطه؛ النتيجة تعرض الوجهين وتبرز الفائز بإطار ذهبي وتاج SVG. التعادل دون تاج، والحسم المبكر يبقي توضيحه وعدد المربعات المحسومة.
- «إعادة اللعب» تحتفظ بالشخصيات واللوحة ونمط الخصم والصعوبة وخيار من يبدأ، وتبدأ بنقاط وشبكة فارغتين. خيار البداية العشوائية يُسحب مجدداً لكل مباراة.
- «تغيير الشخصيات» ترجع مباشرة للاختيار مع بقاء إعدادات المواجهة؛ «شبكة أخرى» والرئيسية باقيتان متاحتين.

## 🔧 التقنيات المستخدمة

- **React Native**: إطار العمل الأساسي
- **TypeScript**: للكتابة الآمنة
- **React Native SVG**: لرسم لوحة اللعب
- **Context API**: لإدارة حالة الصوت والإعدادات
- **Hooks**: لإدارة حالة المكونات

## 📝 ملاحظات التطوير

- تُحفظ إعدادات الصوت والموسيقى والتأثيرات ومعرّفات الشخصيات تلقائياً عند تغييرها، وتُستعاد عند فتح التطبيق. لا يلزم الضغط على زر حفظ.
- التفضيلات القديمة التي تحتوي ألواناً فقط تحصل على الشخصيات الافتراضية مع الحفاظ على الصوت. المعرفات غير الصالحة أو المكررة ترجع أيضاً للاختيار الافتراضي الصالح.
- التخزين محلي عبر `@react-native-async-storage/async-storage`؛ على الويب يرتبط بالمتصفح والموقع. حذف بيانات التطبيق أو الموقع يحذف الاختيارات.
- لاختبار الاستعادة يدوياً: اكتم الموسيقى، غيّر مستوى النقر وشخصية اللاعب 1، ثم أغلق التطبيق بالكامل وافتحه مجدداً. تحقق أيضاً من الرجوع من اختيار الشخصيات والعودة إليها، ومن تعيين الشخصية الأخرى للهاتف في وضع CPU، وأن إعادة تعيين الصوت لا تمس اختيار الشخصيات.
- شغّل `npm.cmd test` للتحقق من استعادة الاختيارات والتحقق من البيانات وترتيب الحفظ والتعامل مع أخطاء التخزين.
- اختبارات المرحلة الثانية تتحقق أيضاً من هوية اللاعب والشخصية في الوضعين، صور النتيجة والتاج والتعادل، وتمرير معرّفات الشخصيات وبقاء إعدادات المواجهة عبر التنقل. اختبارات المكونات تستبدل الأسطح الأصلية فقط؛ التحقق من اللمس والصوت الفعلي يحتاج متصفحاً وهاتفاً حقيقياً.
- فحوص التطوير: `npx.cmd tsc --noEmit` و`npm.cmd run lint` و`npm.cmd test` و`git diff --check`.

- يستخدم الصوت ملفات محلية عبر `expo-audio`.
- على الويب قد يمنع المتصفح التشغيل التلقائي للموسيقى حتى أول تفاعل من المستخدم.
- النظام يدعم إضافة لاعبين إضافيين بسهولة
